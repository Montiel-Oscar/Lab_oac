2. Carta ASM propuesta

La carta se muestra por bloques de estado para evitar cruces de líneas. Cada bloque conserva la notación ASM estándar: rectángulo = estado, rombo = decisión, rectángulo redondeado = salida condicional y etiqueta final = siguiente estado.

Estado Decisión Salida condicional Sx Siguiente estado
Punto clave: en S1 primero se evalúa B. Si B=0 se pasa directamente a S2. Si B=1 aparece una segunda decisión sobre C: C=0 lleva a S3 y C=1 activa condicionalmente Y1=1 antes de pasar a S4.

5. Método numérico de Quine-McCluskey

Orden de variables utilizado:

Q2, Q1, Q0, A, B, C

Ejemplo: Q2Q1Q0ABC = 001011₂ = 11₁₀. Los estados 110 y 111 generan:

d = Σd(48-63)

5.1 D2

Minterms:

D2 = Σm(11,15,17,19,21,23,28,29,30,31,32,33,36,37,41,43,45,47)

Con d = Σd(48-63), la combinación y selección de implicantes primos produce:

D2 = A Q0 Q1 + C Q1 Q̄0 + C Q2 B̄ + Q2 B̄ Q̄0 + B C Q0 Q̄1

5.2 D1

Minterms:

D1 = Σm(8,9,10,12,13,14,16,18,20,22)

Combinaciones representativas:

010000, 010010, 010100, 010110 → 010--0 → Q1 Q̄0 C̄
001000, 001001, 001100, 001101 → 001-0- → Q0 Q̄1 Q̄2 B̄
001000, 001010, 001100, 001110 → 001--0 → Q0 Q̄1 Q̄2 C̄
D1 = Q1 Q̄0 C̄ + Q0 Q̄1 Q̄2 B̄ + Q0 Q̄1 Q̄2 C̄

5.3 D0

D0 = Σm(4,5,6,7,10,14,17,19,21,23,32,33,34,35,36,37,38,39,41,43,45,47)

Con d = Σd(48-63):

D0 = C Q2 + Q2 Q̄0 + C Q1 Q̄0 + A Q̄0 Q̄1 + B Q0 C̄ Q̄1 Q̄2

6. Minimización de las salidas

Y1 - lógica positiva

Y1 = Σm(11,15,24,25,26,27,28,29,30,31)
Y1 = Q0 Q1 + B C Q0 Q̄2

Y2 - lógica positiva

Y2 = Σm(28,29,30,31,40,41,42,43,44,45,46,47)
Y2 = Q0 Q2 + A Q0 Q1

Ȳ3 - lógica negada

Activa en S2=010 cuando C=1.

Y3(activa) = Q1 Q̄0 C
Ȳ3 = Q0 + Q̄1 + C̄

Ȳ4 - lógica negada

Activa en S4=100 cuando B=0.

Y4(activa) = Q2 Q̄1 Q̄0 B̄
Ȳ4 = B + Q0 + Q̄2
